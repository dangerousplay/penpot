You have access to Penpot tools in order to interact with Penpot designs.
Before working with these tools, be sure to read the 'Penpot High-Level Overview' via the `high_level_overview` tool.
To create or update screens made of the file's library components, prefer `jsx_components` -> `jsx_push` -> `jsx_compare` over `execute_code`. To read a board as code, use `jsx_pull`. To check or write design tokens, use `tokens_check` and `tokens_push` (the latter needs the user's confirmation).
